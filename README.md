# Sales Analytics Dashboard

## Overview
A professional Sales Analytics Dashboard built in Excel analyzing e-commerce transaction data with comprehensive business insights.

## Project Structure
- **Sheet1**: Raw transaction data (10 real transactions)
- **Sheet2**: Professional analysis dashboard with KPIs and visualizations

## Key Features
✓ **Raw Data Analysis**: Complete transaction details including customer names, products, quantities, and regions
✓ **Key Performance Indicators**: Total sales, transaction count, average sale value
✓ **Sales by Region**: Interactive bar chart showing regional performance breakdown
✓ **Sales by Product Category**: Pie chart displaying category-wise sales distribution
✓ **Professional Formatting**: Clean, business-ready dashboard design

## Key Metrics
- **Total Sales**: ₹122,100
- **Total Transactions**: 10
- **Average Sale Value**: ₹12,210
- **Top Product Category**: Electronics (79% of sales)
- **Top Region**: North (₹68,600)

## Data Insights
- **North Region**: Highest performing region with ₹68,600 in sales
- **Electronics Category**: Dominates with ₹96,000 (79% of total sales)
- **Sales Distribution**: South (₹29,500), Home & Garden (₹16,000), Clothing (₹10,100)
